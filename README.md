# Copolymer_Sequencing_from_Spectra

This repository contains code and supporting materials for the manuscript:

Testing the Limits of Transformer-Based Sequence Inference from Copolymer Spectra

Included is code for data generation, including sequence generation and simulation of NMR, UV-Vis, and mass spectra for D-A copolymers, as well as code for training and analyzing results from the multi-spectra-to-sequence transformer model. 

## Repository Contents

The repository is currently being organized and will be updated with the code and materials needed to reproduce the results presented in the manuscript.

## Reproducibility

Detailed instructions for installing dependencies, running the models, generating spectra, and reproducing the figures and results will be added.
