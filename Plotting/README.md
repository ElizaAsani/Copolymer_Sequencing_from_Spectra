# Plotting

Generates the diagnostic and publication figures for the copolymer sequencing project, drawing on outputs from the Data Generation and Multispectra-to-sequence Transformer pipelines.

## Folder structure

```text
.
├── figure.mplstyle              # matplotlib style for paper figures 
├── plotting_script.py           # entry point: generates all paper figures
├── plot_degeneracies.py         # Figure 3
├── plot_reconstruction.py       # Figure 4
├── plot_subgroup_distance.py    # Figure 5, S6
├── subgroup_vector_distance.py  # k-mer/fragment distance helper for plot_subgroup_distance.py
├── process_mixture_results.py   # merges per-spectrum mixtures beam search results, computes mixture stats
├── plot_mixtures.py             # Figure 6, S7, S8
├── diagnostics.py               # standalone diagnostic plots (loss curves, error counts, beam histograms)
├── example.py                   # standalone example plots for single-sequence spectra
└── example_mixture.py           # standalone example plots for mixture spectra
```

## Paper figures

```bash
python plotting_script.py
```

Run from within this folder. `plotting_script.py` expects the Data Generation, Multispectra-to-sequence Transformer, and Plotting folders to be siblings (as in the main repo), and pulls its inputs from:

- `../Data Generation/degeneracy/` — spectral degeneracy results (Figure 3)
- `../Multispectra-to-sequence Transformer/Output/` — trained model results for each spectrum combination and noise level (Figures 4, 5, S6)
- `../Multispectra-to-sequence Transformer/Output/.../mixtures_L10/` — beam search results on mixtures data (Figures 6, S7, S8), using the same `run_mixtures.yaml` config.

The spectrum combinations and noise levels that are plotted are defined at the top of `plotting_script.py`:

```python
models = {"NMR": "nmr",
          "MS": "ms",
          "UV-Vis": "uv_vis",
          "UV-Vis + MS": "multispectra/uv_vis+ms",
          "UV-Vis + MS + NMR": "multispectra/all/"}
 
noise_levels = ["NOISE0", "NOISE1", "NOISE2"]
```

Each key in `models` should correspond to a trained model's `output_dir` (relative to `Output/`) from a completed Transformer run. Figures are saved as `.svg` alongside their source data, mostly under each model's `output_dir`; separate legend files (e.g. `reconstruction_legend.svg`, `dist_legend.svg`) are written to the current directory.

`build_model_folders` (in `plotting_script.py`) resolves the `models`/`noise_levels` combinations into output paths and is reused across the calls above.

### Computing files

Two helper files are included:

- `subgroup_vector_distance.py`, which is used to compute the vector of trimer/end-groups for sequence structure comparisons in `plot_subgroup_distance.py`
- `process_mixture_results.py`, which merges the output of all mixture predictions into a single file and computes mixture predictions for sequence length, fraction of donor monomers, and average block length. The output files generated by `process_mixture_results.py` are stored in the output directory for the complete multispectra model; these files are read by `plot_mixtures.py` to plot the mixture results.  

## Diagnostic plots

```bash
python diagnostics.py <output_dir>
python diagnostics.py <output_dir> --only loss
python diagnostics.py <output_dir> --only errors
python diagnostics.py <output_dir> --only beam --alpha 1.0 --th 1
```

Tools for plotting diagnostics for a single Transformer run's `output_dir` (independent of `plotting_script.py`). Uses plain matplotlib defaults, not `figure.mplstyle`, since these are for quick inspection rather than publication.

- `loss` — train/validation loss curves from `loss_history.csv`
- `errors` — histogram of reconstruction error counts, and average errors vs. sequence length, from `errors/errors.csv`
- `beam` — beam search score distributions for a sample of individual sequences, from `beam_search/alpha_<alpha>/beam_search.csv`; `--th` defines an upper bound for the top beam score, i.e. if set to `--th 0.90`, will only plot beam score distributions for sequence predictions where the top score is less than 0.90, i.e. where there is uncertainty in the beam predictions.

## Example plots

```bash
python example.py --config <config_file.yaml> --output_dir <output_dir> --sequence 'ADDAADAAAD'
python example_mixture.py --config <config_file.yaml> --output_dir <output_dir> --n 5
```

Tools for plotting example spectra for either single sequences or mixtures.

For single sequences, use `example.py`, which reads in a config file (must contain configs for all spectra), generates UV-Vis, NMR, and mass spectra for the given sequence, and saves to the output directory within `./examples/`.

For mixtures, use `example_mixture.py`, which reads in a config file and generates UV-Vis, NMR, and mass spectra for `n` mixtures per lambda specified in the config. The mixtures are read from an already-generated `mixtures_lamb{lambda}` file in `Data Generation`. The examples are stored in a directory for each lambda, under the output directory within `./examples/`.
